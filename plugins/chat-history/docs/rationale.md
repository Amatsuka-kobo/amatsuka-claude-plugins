# chat-history の設計根拠

各スキルの指示から退避した根拠・背景をまとめる。スキル本文には指示だけを置き、判断の由来はここに残す。

## chat: ユーザー発言を原文で残す理由

ユーザーの発言は要件の一次資料である。AI の解釈で置き換えて記録すると、AI が要件を誤解していた場合に「AI の誤解」が「ユーザーの要求」として歴史に残り、後から検証する手段が失われる。発言は会話全体のごく一部であり、原文保存のコストはほぼゼロで済む。

## chat: 引用ブロックと地の文を対応させる理由

引用ブロック(`>`)を発言の原文、地の文を要約・言い換えに固定するのは、読み手が「これは本人の言葉か、AI の解釈か」を常に判別できるようにするためである。この対応が崩れると、記録全体の一次資料としての価値が失われる。

## recall: 既定で全ユーザーの記録を検索する理由

過去の決定は誰のセッション由来でも価値がある。作業者で絞ると、他者が決めた前提を見落としたまま同じ議論を繰り返すことになる。
