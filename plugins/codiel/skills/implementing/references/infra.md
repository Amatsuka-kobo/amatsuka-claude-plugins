# Infra 実装の注意

- 既存の IaC のモジュール構成・命名・変数の渡し方に合わせる。
- 秘密情報を平文でコードや変数のファイルに書かない。state ファイルや秘密を含む変数のファイルをコミットしない。
- リソースの置き換え・削除・停止を伴う変更を避ける。避けられないときは完了報告に挙げる。
- イメージのタグ、プロバイダ、CI のアクションなどのバージョンを固定する。
- 権限を必要な範囲に絞る。IAM のワイルドカード、特権コンテナ、root での実行を足さない。
- プロジェクトに検証のコマンドの定めがあれば実行する。`terraform validate` と `plan`、マニフェストのドライラン、Dockerfile や CI の定義の lint が当たる。
- 本番へ反映する操作(`apply`、デプロイ、レジストリへの push)は実行しない。
