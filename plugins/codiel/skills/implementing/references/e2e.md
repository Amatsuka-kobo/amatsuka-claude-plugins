# E2E の実行とテストの実行環境

通すテストに E2E の仕様のディレクトリがあるときは、仕様のディレクトリごとにテストフレームワークを 1 回起動する。
JSON の出力と、frontend では各ケースの最後の画面のスクリーンショットを、依頼文(worktree の委譲では brief)が指す実行ごとのディレクトリに出す。
返答に入れる項目は `../../../references/e2e-report-format.md` に従う。

E2E の実行に要る準備(サーバーの起動、データベースの用意など、依存のインストールを超えるもの)は、プロジェクトの規約とテストの設定に従う。準備の手順は codiel が持たない。

理由が環境にある失敗(サーバーが起動しない、接続が拒否される、ポートが使用中、必要なサービスが無い)は、通すテストの失敗にもプロダクトの失敗にも数えず、環境の失敗として理由と出力の抜粋を完了報告に挙げる。
