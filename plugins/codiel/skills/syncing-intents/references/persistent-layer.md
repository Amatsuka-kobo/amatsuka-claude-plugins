# 持続層への取り込み

承認済みの intent から、領域ごとの持続層(`docs/intents/domains/<領域>.md`)へ制約を取り込む。受け入れ基準等の反映とは別の作業で、intent の `domains` が領域を持つときに読む。

## 手順

1. intent 文書のパス、取り込み先の領域(intent の frontmatter `domains`)、`state.knowledgeTarget` の値を読み取る。領域が複数あれば、領域ごとにこの手順を繰り返す。
2. 領域ファイルが無ければ、書式の正本(`intent-format.md` の「持続層」セクション)どおりの見出し(`## GOTCHAS 候補` を除く)だけを持つ空のファイルを作る。
3. intent の `## 目的` を読み、領域ファイルの `## 目的` へ取り込む。
4. intent の `## 意図的な制約`(「制約 | 理由」の表)の行を、1 行を 1 件として、領域ファイルの `## 意図的な制約` へ取り込む。行の「制約」列を `- 制約:`、「理由」列を `- 理由:` に対応させる。
   - 既存の制約と同じ内容を別の intent が持ち込んだときは、制約を増やさず、その項目の `出典 intent` に今回の intent のパスを加える。
   - 既存の制約と矛盾する内容は、上書きせず、矛盾の内容を書かずにユーザーへ確認する。
   - 参照形のエントリは確定済みとして扱い、全文を書き戻さない(参照形とは `関連 ADR: ADR-NNN(候補 ID: <候補 ID>)` の 1 行だけを持つエントリである)。今回の変更がその制約を変える内容なら、書かずにユーザーへ確認する。
   - ADR の 3 条件(覆すコストが大きい・選択肢が実在した・理由が自明でない)を満たす新しい判断は、ここで取り込まず、次の「ADR 候補の扱い」に従う。
5. intent の `## 非スコープ` を読み、領域ファイルの `## 非ゴール` へ取り込む。
6. 領域ファイルの `## 由来` に、今回取り込んだ intent のパスを `- docs/intents/YYYY-MM-DD-<slug>.md(取り込み日 YYYY-MM-DD)` の形で 1 行加える。
7. 取り込みで引いた出典があれば、領域ファイルの `## 出典` へ追記する。`## 出典` は常に最後のセクションに保つ。
8. 手順 4 で ADR の 3 条件を満たした判断と、次の 3 種の対象のうち 3 条件を満たした判断を、次の「ADR 候補の扱い」に従って手元の記録に書き、`intents` のときは領域ファイルへ写す。
   - intent の `## 合意済み事項` の表の行。1 行を 1 件として判定する。
   - この try の `design.md` の `## 方針` で採用した案。1 案を 1 件として判定する。`design.md` が無い軽量の経路では判定しない。
   - carry-over で「修正して再提出」を選んだ後の、`startHead` からの `codiel(carry-over):` のコミットの修正判断。コミットの内容と carry-over の所見から、1 つの修正方針を 1 件として判定する。carry-over を行わなかった try では判定しない。
   同じ判断が `## 意図的な制約` の行と重なるときは、1 件にまとめる。この手順は手順 9 より前に済ませ、写した領域ファイルをゲートの `paths` とゲート通過直後のコミットに間に合わせる。
9. 取り込んだ領域ファイルのパスと、書かずに終えた矛盾を、`.codiel/runs/<slug>/try-<n>/steps/intent-sync/report.md` に書き残す。このファイルはコミットしない。再開では、このファイルがあれば取り込みは済んでいる。領域ファイルのコミットは、ゲート通過直後に行う。

## ADR 候補の扱い

ADR の 3 条件を満たす判断は、`state.knowledgeTarget` の値によらず、`<plugin-root>/skills/orchestrating-runs/references/adr-candidates.md` の手順で run の手元の記録に ADR 候補として書く。

- `metatron` のとき: 領域ファイルへは何も書かない。`[ADR 候補]` のエントリも `関連 ADR` の行も作らず、判断は手元の記録にだけ残る。
- `intents` のとき: 同じ手順で、手元の記録から領域ファイルの `## 意図的な制約` へ `[ADR 候補: <候補 ID>]` の形で写す。
