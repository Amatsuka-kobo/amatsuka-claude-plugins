# E2E のレポートの運転

E2E を実行する委譲を出す前に読む。置き場・名前・md の形・書く時点・`failure.md` の直し方は `<plugin-root>/references/e2e-report-format.md` に従う。

- 実行ごとのディレクトリの名前と置き場の絶対パスは、実行の前に決めて、依頼文(worktree の委譲では brief)に書く。
- 修正の委譲(implement のタスクレビューの修正ラウンドとグループのマージの後の修正、test-loop の修正)には、失敗した仕様のディレクトリの最新のレポート(名前の順で最後の実行ごとのディレクトリ)の絶対パスを渡す。
- レポートのコミットは次の 2 つの契機で行う。コミットするものが無ければ行わない。git に載るのは `results.json` と md だけで、画像は `.gitignore` が外す。
  - `evaluate_code` を呼ぶ前: そのフェーズで作った実行ごとのディレクトリと、そのフェーズで直し方を書き換えた前のフェーズの `failure.md` を `git add -- <パス>` し、`codiel(<phase>): E2E のレポート (<slug> try-<n>)` でコミットする。
  - `codiel-state stop` を呼ぶ直前: まだコミットしていない実行ごとのディレクトリと `failure.md`(直し方を「なし」に書き換えたものを含む)を、同じ形でコミットする。
- Raguel は差分を自分で作ってレポートを評価から外すので、`evaluate_code` には E2E のレポートの除外を渡さない。
- PR・Issue・コメントに証拠を載せるときは、レポートの画像とログを使い、画像は `imageUpload` の手段で載せる。local モードと手段が無いときは、画像の置き場(実行ごとのディレクトリ)を本文に書く。
