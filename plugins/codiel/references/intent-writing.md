# intent 文書の執筆規則

この規則は、変更ごとの intent、持続層、triage が local モードで書く intent 草案に適用する。

## 文の組み立て

- 言い切りで書く。命令形は使わない。
- 1 つの文に、1 つの内容だけを書く。
- 本文は箇条書きで書く。見出しの概要や 1 文だけの指示、箇条書きにすると文脈が壊れる内容は、散文で書く。
- 太字や記号で指示を強調しない。指示の重さは条件と範囲で示す。
- 出力の形を示す例を置くときは、それが例であることと、値を実際の内容に置き換えることを明記する。判断を示す例は、性質の違うものを 2 つ以上置く。
- 保つべき内容を保てる範囲で、最も短い文にする。

## 根拠と背景の残す基準・削る基準

過剰な根拠と背景は削り、必要なものは残す。基準は次のとおりである。

| 扱い | 対象 |
| --- | --- |
| 残す | 制約を意図して置いたと分かる理由(後の変更者が偶然の制約と区別するため) |
| 残す | 合意済み事項がその選択肢に決まった理由 |
| 残す | 適用範囲や優先順位を判断する材料になる理由 |
| 削る | 議論の経過の語り |
| 削る | 実測値の詳細(結論と出典への参照だけを残す) |
| 削る | 採らなかった案の長い説明(理由 1 行だけを残す) |
| 削る | 同じ理由の言い換え |

## 出典の置き場

引用・出典は削らず、文書末尾の `## 出典` セクションにまとめる。出典が無ければ「なし」と書く。

## 原文のセクションの扱い

原文のセクションには削る基準を当てず、ユーザーの言葉を原文のまま保つ。原文のセクションには文の組み立ての規則も当てない。この規則を当てるのは派生文のセクションと記録のセクションだけである。

持続層には原文のセクションを置かない。原文は変更ごとの intent にだけ置く。

triage が local モードで書く intent 草案は、書式のうえで原文のセクションの見出しを持つが、ユーザーの言葉がまだ無い。その見出しの下には `<!-- codiel:unrecorded -->` を置く。
