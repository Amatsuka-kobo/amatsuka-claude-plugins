# AI 向け指示書の鍛錬

対象は CLAUDE.md・SKILL.md・コマンド定義(`commands/*.md`)・output style・Agents 定義・メモリの本文と、`references/` に置かれた文書である。
`references/` の文書は、人間も読む内容であっても対象とする。
対象は `references/` というディレクトリ名で決まり、どのプラグインの配下かは問わない。
README・設計書・チュートリアル・`docs/` の文書には適用しない。指示書がこれらを参照していても、対象は参照先へ広がらない。
frontmatter の description には適用しない。description を書くときは `../../references/description-guide.md` に従う。

## 削る基準

- 指示を正当化する根拠・理由は削り、指示だけを残す。
- 出典・引用・経緯は削る。どこから来たか、いつ決まったかは振る舞いを変えない。
- 重複は削る。同じ指示の言い換え、要約と本文の重なりは一方だけを残す。
- 判断基準のない修飾(「適宜」「必要に応じて」「できるだけ」)は、基準に置き換えられるなら置き換え、
  置き換えられないなら修飾ごと削る。
- 文書自身の構成や意図の説明(「この文書は〜を説明する」)は削る。適用範囲の限定は残す基準に従う。
- 例は 1 つで伝わるなら 2 つ目以降を削る。
- 引くために置かれた記述(外部仕様の写し、フィールドやスキーマの定義、網羅を要する列挙)には、
  重複・例・出典の基準を当てない。網羅と原典への追跡可能性がその記述の役割である。

## 引くための記述の見分け方

- 判定の単位は見出し配下のブロックとする。表・その表を導入する文・表の直後の補足は 1 ブロックとして同じ扱いにする。
- ブロック内で判定が割れるときは、そのブロックが「開いた者が値を引く先」か「読んだ者の動きを変える文」かで決める。前者は例外、後者は通常適用とする。
- 迷ったブロックは通常適用に倒し、指摘として挙げてユーザーの判断を仰ぐ。
- 例外がかかるのは重複・例・出典の 3 基準だけである。書き方の基準・残す基準は引くための記述にも当てる。

## 残す基準

- 読んだ後にエージェントの振る舞いが変わる文は残す。
- 誤読を防ぐ制約(順序・範囲・例外・優先順位)は残す。
- 判断基準そのものは残す。
- 同じ文が削る基準と残す基準の両方に当たるときは、残す基準を優先する。

## 書き方の基準

- 命令形(「〜すること」)ではなく、望ましい動きの言い切り(「〜する」「〜しない」)で書く。
- 1 文に 1 指示だけを書く。複数の指示を 1 文に詰めない。
- 禁止を書くときは、代わりに取る動きを併記する。「〜しない」だけで終えない。

## 工程

- 新規に書くときは、素案を書き切ってから別のパスで基準を当てて削る。生成と削減を同じパスで行わない。
- 既存の指示書を見直すときは、文単位で走査し、各文を保持・削除・退避・書き換えのいずれかに判定する。
- 削除と退避の分岐は内容の種別で決める。将来の判断や調査の入力になる種別(根拠・実測値・経緯・
  不採用案)は退避、それ以外(言い換え・修飾・文書自身の説明)は削除。迷った文は退避に倒す。

## 評価

既存の指示書を評価するときは、次の順で出力する。

1. 評点表。冗長度・充足度・スタイル適合の 3 軸と、その評点を並べる。例外として除いた範囲があるときは、
   表の直後に「例外(引くための記述)として除いた範囲: <見出し名>」を書く。
2. 指摘リスト。番号を振り、1 件ごとに 該当箇所 / 当たった基準 / 判定(削除・退避・書き換え) を書く。
   判定が退避・書き換えのときは置き換え後の文言も書く。判定が削除のときは書かない。
3. 適用の可否を尋ねる。「全件」と「番号指定」の双方を受け付け、承認された項目だけを直す。

複数の指示書を一度に評価するときは、評点表を 1 つに束ね、指摘リストは指示書ごとに区切って通し番号を振る。
文の総数・評点・例外の除外は指示書ごとに出し、合算しない。

指摘は 1 箇所につき 1 軸にのみ計上する。書かれている不要な内容は冗長度、書かれていない内容は
充足度、文の書き方はスタイル適合に振り分ける。1 箇所が複数の軸に読めるときは、この順で
先に当たった軸に計上する: 冗長度 → 充足度 → スタイル適合。

| 軸 | 当てる基準 |
| --- | --- |
| 冗長度 | 削る基準 |
| 充足度 | 残す基準の裏返し(判断基準・制約・優先順位が要る箇所で書かれていない) |
| スタイル適合 | 書き方の基準 |

評点は、その軸の指摘件数を文の総数で割った比率から決める。箇条書きの 1 項目と散文の 1 文を
それぞれ 1 と数える。表は、ヘッダ行と区切り行を除いた 1 行を 1 と数える。充足度の欠落は、
書かれていない項目の種類ごとに 1 と数える。frontmatter は文の総数に数えず、指摘の対象にもしない。
引くために置かれた記述も文の総数に数えない。除くのは比率の分母だけで、指摘の通し番号には影響しない。

| 比率 | 評点 |
| --- | --- |
| 0% | 5 |
| 0% 超 10% 以下 | 4 |
| 10% 超 25% 以下 | 3 |
| 25% 超 50% 以下 | 2 |
| 50% 超 | 1 |

対象外の文書を渡されたときは、評価せず適用範囲の外であることを伝える。

## 退避

- 退避する内容は、`docs/` の設計書など毎回は読み込まれない置き場へ移し、移動先を報告する。
- 退避先に `references/` は選ばない。そこも対象範囲であり、移した内容が次の評価で再び削る基準に当たる。
- 決まった置き場がないリポジトリでは、移動先を提案してから移す。
