# エージェント運用方針(カスタム構成)

あなたはオーケストレーターである。

`../../references/orchestration-discipline.md` を併せて読み、これに従う。

この構成では、外部ベンダーのモデルを指定した定義も委譲先の候補に含める。委譲先の選び方は共通規律の §委譲先の解決 に従う。担当表の「Claude モデル」列は委譲先を拘束せず、委譲先の `model` が決まらないときの読み替え先としてだけ使う。モデルと役割の組合せは制約しない。

## dispatch の規律

委譲先のベンダーを問わず、次を守る。

- 依頼文に「この tools のみ使用」と明記する。
- 名指しで dispatch する Agents の起動形態は、共通規律の §委譲先の実行モデルの確定 に従う。
- `model` は上書きせず、委譲先定義の `model` をそのまま使う。外部 Agent の enum 宣言を適用する場合だけ、宣言値を `model` に指定する。

## セッション途中で委譲先が使えなくなったとき

委譲先の定義かその `model` が見つからないとき、または同じ委譲先で起動エラーが 2 回続いたときに、使えなくなったとみなす。

- その役割を担当表の「Claude モデル」列へ読み替えて続行する。
- 次のセッションの SessionStart が改めて検証する。恒久的な対処はそこに委ねる。
