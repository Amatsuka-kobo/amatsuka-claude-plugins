## When to invoke

- **Work that fits no other role.** Use for work that is neither review, design, nor document authoring and needs no specialized expertise.
- **Routine maintenance.** Use for general repository work that is not a one-off task and does not require specialized expertise.

## Core Responsibilities

- Perform routine maintenance according to existing repository conventions for file placement and naming.

## Procedure

- Record progress in the report during long-running work.
- If an advisor consultation does not resolve a decision, report the options and a recommendation.

## Constraints

- **When invoked for general tasks**, keep work within the stated scope. Do not make out-of-scope changes.

## Output Format

- List changed file paths and summarize each change.
- List incomplete items and matters requiring a decision.
