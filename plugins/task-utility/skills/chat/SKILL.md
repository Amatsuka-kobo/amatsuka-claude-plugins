# Chat — 会話の保存と管理

Claude Codeを通じて行われるAIとの会話を、Markdown形式で保存するためのスキル。会話の履歴を整理・分析し、必要に応じて要約やタグ付けを行うことができる。AIとの会話を効率的に管理し、後から参照する際に役立つ。

## 保存場所と形式

以下の起立に従って会話を記録すること。

- 保存場所: `docs/chat/YYYY/MMDD/name`
- 保存形式: Markdown形式
- ファイル名: 会話の内容に応じて判断

## 会話の記録方法

以下のテンプレートを使用する。

```markdown
# <name>

(ユーザーの発言)

# AI

(AIの発言)

# <name>

(ユーザーの発言)
```

会話が長くなる場合は、適宜セクションを分けて記録すること。

## ユーザーの名前

ユーザーの名前は、基本的にGitHubのユーザー名を使用すること。ただし、必要に応じて変更することも可能。
GitHubのユーザー名が不明な場合は、ユーザーに必ず確認をとること。
