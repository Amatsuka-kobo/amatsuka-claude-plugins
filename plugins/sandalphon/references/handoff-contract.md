# 委譲の呼び出し契約

この契約を変更したら、同じコミットで gh-utility の `skills/issue-craft/SKILL.md` の `## 持ち込みモード` も更新する。

## gh-utility `issue-craft` — 持ち込みモード

確定済みの Issue 本文をそのまま起票させるときに使う。次の固定開始句で起動し、句を言い換えない。

```
持ち込みモード: 以下の完成済み本文で起票
```

続けて次のフィールドを渡す。

| フィールド | 必須 | 内容 |
| --- | --- | --- |
| `title` | 必須 | Issue のタイトル。そのまま使われる |
| `body` | 必須 | Issue 本文の全文。そのまま使われる |
| `labels` | 任意 | 希望ラベル。リポジトリに存在しないラベルは付かない |

## 契約

- `title` と `body` が揃っていないときは委譲しない。欠けたまま起動しても `issue-craft` は持ち込みモードに入らず、不足を呼び出し元へ報告して停止する。
- 渡した本文は改変されない。`issue-craft` は誤字修正・整形・要約・見出しの並べ替えを行わないため、本文は渡す前に確定させる。
- 承認ゲート(全文提示 → 明示承認)は省略されない。ブレストを飛ばすのは内容が確定しているためであり、外部公開行為の承認が不要になるわけではない。
