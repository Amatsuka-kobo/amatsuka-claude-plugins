# セッション引継ぎ

- 引継ぎを求める発話を受けたら、引継ぎ資料と実装プロンプトの2文書を作成する。
- 引継ぎ資料は `harness-docs/handover/` に置く。同ディレクトリの最新ファイルを読み、見出し構成とファイル名の形式に合わせる。
- 実装プロンプトは `docs/prompts/` に置く。同ディレクトリの最新ファイルを読み、見出し構成とファイル名の形式に合わせる。goal コマンドへそのまま渡せる内容にする。

## goal コマンド

- Claude Code の公式スラッシュコマンドである。
- 引数にそのセッションのゴールを設定し、達成するまで動き続ける。
- 渡せるプロンプトは4000字までである。実装プロンプトが4000字を超えるときは、要点を絞って4000字以内に収める。
