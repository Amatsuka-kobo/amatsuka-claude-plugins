**時系列の発見**: エージェント定義は `f875c43`（**2026-07-12**）が最終更新。方針文書 `agents-with-codex.md` はその翌日 `c49127a`（**2026-07-13**「エージェント運用方針を見直し」）で改定。定義は改定を反映していない。

**改定の本質**: 旧方針では「GPT Sol = 通常のレビュー・調査・分析 + 複雑コーディング + オーケストレーション」だったが、新方針で「GPT Sol = 複雑なコーディングと実装計画のみ」に狭められ、レビュー・調査・分析・監査は Fable（設計・監査）へ移譲。委譲先も「Sonnet/GPT Luna」に限定された（旧方針では Terra/Haiku も含む）。

**監査結論（重大度順）**:

**🔴 High — `gpt-sol.md` が旧方針の「アナリスト」像のまま**

- `codex/gpt-sol.md:8` で「上級アナリスト兼実装オーケストレーター」と自己定義
- `codex/gpt-sol.md:12-14` の When to invoke 先頭3つが **コードレビュー / 調査・原因分析 / 設計・技術分析**（旧方針で削除されたセクション）
- `codex/gpt-sol.md:3` の description で「レビュー・調査・分析を委譲するとき」が主トリガー

これらは改定で削除された旧「## レビュー・調査・分析」セクションに対応しており、現行方針では無効。逆に新方針の「複雑コーディング」は委譲表（`:27`）に一度出るだけ、「実装計画」に至っては invoke トリガーとして事実上不在。役割の重心が方針と反転。

**🟠 Medium — `gpt-sol.md` の委譲先が方針の範囲を超過**

現行方針 `agents-with-codex.md:4` は「それ以外を **Sonnet/GPT Luna** にやらせる」と委譲先を明確に2つに限定。しかし `codex/gpt-sol.md:27-32` は Sonnet・GPT Luna に加え **GPT Terra・Haiku** も委譲先に含む。新方針ではその他作業の配分は Fable の職掌であり、GPT Sol が担うべきではない。

**🟠 Medium — `gpt-sol.md` が「設計」を自身の成果物として扱う**

方針 `agents-with-codex.md:8` は「設計はオーケストレータが直接担い、GPT Sol は**アドバイザー**のみ」。しかし `codex/gpt-sol.md:14` は「設計・技術分析…リファクタリング方針の策定」を GPT Sol 自身の invoke 作業として列挙し、助言者の位置付けを超えている。

**🟡 Low — `gpt-luna.md` に Codiel/API 制約が欠落**

`codex/gpt-luna.md:8,15` は「軽微なコーディング」を担うと明記する一方、制約節（`:29-32`）に Codiel/raguel-mcp の **API 不使用**ルール（`gpt-sol.md`・`gpt-terra.md` は保持）がない。Luna が Codiel コードに触れた場合、CLAUDE.md の必須制約が欠けることになる。

**🟡 Low — `gpt-terra.md` はメジャーバージョンの人間確認が未記載**

`codex/gpt-terra.md:33` は「マイナーバージョンを上げる」とのみ記載。`codex/gpt-sol.md:41` にある「メジャー引き上げは人間確認が必要」の但し書きがなく、CLAUDE.md「プラグインのアップデート」節の運用と厳密には非対称（実害は小）。

**却下選択肢なし**: 修正は依頼されておらず、監査依頼のため提案にとどめ、実施しない。

**推奨アクション**: `gpt-sol.md` の刷新（役割を複雑コーディング+実装計画中心に書き換え、レビュー/調査/分析トリガーを削除、委譲先を Sonnet/GPT Luna に限定）を軸に、`gpt-luna.md`・`gpt-terra.md` の軽微な補修（API 制約追加、メジャーVer人間確認の記載）も含めて修正することを推奨。
