## 前提整理

2 つを分離:

1. **帯参加** — 「通常実装が要る→この Agent へ」と役割 dispatch の宛先になること。監査が marker opt-in 必須とした領域
2. **モデル割当** — 名指しで dispatch される時、model 未定義ならどのモデルで動かすか。あなたの要望の実体

割当機構は既存で完結:
- Claude 帯 → dispatch 時 `model` 上書き(enum: sonnet/opus/haiku/fable)
- GPT/Grok 帯 → 定義本文を同梱プリセット(`agent-policy:gpt-*`/`grok`)へ移植。`model` param に proxy alias 渡せない → hook 強制不可能な帯

欠けているのは「**帯の決定を、どこで・何を根拠に・永続的に行うか**」。

## 案

### 案A(推奨): サイドカー割当マップ = marker の外部化

- `.claude/agent-policy/assignments.json`(等)に `Agent 名 → role id` の明示マップ。**ファイル所有権不要の opt-in** — plugin/user/nested Agent 全対象
