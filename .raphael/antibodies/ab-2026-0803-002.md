マルチラインシェルコマンドを Bash ツール経由で実行する場合、改行がスペースに置換される可能性がある。改行に依存しないコマンド構文が必須。

問題: 複数行コマンドを改行のまま入力すると、cd や git などのコマンドが正しく実行されない。

例 (失敗):
  cd /path/to/project
  git checkout -b branch-name
  # 実行結果: "cd /path/to/project git checkout ..." のようにスペース置換され、cd が失敗

例 (正しい):
  cd /path/to/project && git checkout -b branch-name && git status

シェルコマンドを複数ステップで実行する場合は、必ず && で連結する。改行は使わない。|| で条件分岐や; で無条件連結もあるが、通常は && が安全。複数行に見せたい場合は バックスラッシュ継続 (\) を使い、実際のコマンドラインでは && で連結する。
