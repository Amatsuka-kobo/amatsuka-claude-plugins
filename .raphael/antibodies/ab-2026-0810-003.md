git diff --check は末尾の空白行やスペース・タブの混在を検出し、エラーで終了します。

エラー例: ".raphael/antibodies/ab-2026-0802-001.md:40: new blank line at EOF."

原因: ファイルの最後に不要な空白行や末尾スペースがある。git の whitespace validation が引っかかります。

解決方法:

1. 末尾の空白行を削除（sed で一括処理）:
   sed -i -e :a -e '/^[[:space:]]*$/d;N;ba' /path/to/file

2. または手動編集でファイル末尾の余分な空白行を削除する

3. 修正後に git diff --check で再検証:
   git diff --check  # 成功すれば出力なし、exit code 0

複数ファイルを一括修正:
  git diff --check | sed 's/:.*$//' | sort | uniq | while read f; do
    sed -i -e :a -e '/^[[:space:]]*$/d;N;ba' "$f"
  done

この検証は git pre-commit hook で自動実行されることが多い。コミット前に git diff --check で必ず確認すること。末尾スペースや CRLF 混在も同様に検出されます。
