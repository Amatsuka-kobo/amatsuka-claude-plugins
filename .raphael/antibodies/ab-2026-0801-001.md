複雑なシェルコマンドの作成時に、cd コマンドで作業ディレクトリを変更した後、元ディレクトリ基準の相対パスを使用すると、パス解決に失敗する。

cd で cwd が変わった場合、その後のコマンドはすべて新しい cwd を基準にパスを解決する。元ディレクトリの相対パスは無効になる。

例 (誤)：
  cd plugins/task-utility/skills/issue-craft
  wc -l plugins/task-utility/skills/*/SKILL.md    # 失敗: plugins/task-utility は issue-craft から見えない

例 (正)：
  # 方法1: 絶対パスを使う
  cd plugins/task-utility/skills/issue-craft
  wc -l /absolute/path/plugins/task-utility/skills/*/SKILL.md

  # 方法2: サブシェルで cd を隔離
  (cd plugins/task-utility/skills/issue-craft && do_something)
  wc -l plugins/task-utility/skills/*/SKILL.md

  # 方法3: cd と復帰を同じコマンドで行う
  cd plugins/task-utility/skills/issue-craft && do_something && cd -

複数ステップのシェルコマンドでは、cd 後のパス解決が cwd 基準になることを常に考慮する。
