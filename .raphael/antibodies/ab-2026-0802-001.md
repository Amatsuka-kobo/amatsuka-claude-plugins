skill-creator の run_eval.py / run_loop.py は、現行の Claude Code ではスキルの発火を検出できない。

これらは測定対象を .claude/commands/ にスラッシュコマンドとして登録する。Claude Code の現行版ではコマンドと skills が別系統であり、コマンドは /名前 で明示呼び出しするものなので、自然文の依頼からは選ばれない。検出側は Skill ツールの呼び出しを見ているため、結果が常に「発火せず」になる。

この故障に気づかず description を書き換えると、壊れた測定に合わせて本番を改悪する。

代わりに plugins/optimize-agents/scripts/run-trigger-eval.mjs を使う:

  node plugins/optimize-agents/scripts/run-trigger-eval.mjs \
    --skill <SKILL.md のパス> \
    --eval-set <クエリ JSON> \
    --runs 2 --workers 6

2026-08-01 の実測: 同一 description・同一クエリで、登録先を .claude/skills/ に変えると resume の発火が 1/8 から 8/8 になった。skill-creator 公式の description をその想定用途どおりの英語クエリで測っても発火率 0 だった。

詳細は plugins/task-utility/evals/README.md と plugins/optimize-agents/docs/description-out-of-scope.md を参照する。
