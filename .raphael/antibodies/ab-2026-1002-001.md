grep -c はマッチ 0 件でも文字列 "0" を stdout に出力してから exit code 1 を返す。`grep -c 'pattern' file || echo 0` のようなコマンドで、0 件マッチした場合、出力は "0" (from grep) と "0" (from echo) の 2 行になる。シェルの [ ] 条件分岐で `c=$(grep -c ... || echo 0)` とすると、$c は複数行を含むため [ "$c" -gt 0 ] で "integer expression expected" エラーが発生する。対策: (1) grep の出力を行単位で処理し最後の行のみを取る `grep -c ... | tail -1 || echo 0`、(2) grep 成功時のみ出力する `grep -c ... && echo "found" || echo 0`、(3) test -f やファイル存在確認で事前にチェックしてから grep を実行する、のいずれかを選択する。
