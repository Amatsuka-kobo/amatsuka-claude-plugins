npm と pnpm は異なるパッケージマネージャーである。package.json や package-lock.yaml の形式が異なり、npm で npm install を実行した場合と pnpm で pnpm install を実行した場合で結果が異なる。特に devEngines で packageManager が pnpm に指定されている場合、npm コマンドは EBADDEVENGINES エラーで拒否される。PATH 操作、env 変数の無視（env -u npm_config_userconfig）、engine 制約の無視（npm_config_engine_strict=false）などの環境変数による回避は効果がない。使用するパッケージマネージャーはプロジェクトの設定で指定されているため、それに合わせてコマンドを使い分ける必要がある。根本的な対処は pnpm に切り替えるか、package.json の devEngines.packageManager を削除すること。
