npm と pnpm は異なるパッケージマネージャーである。package.json や package-lock.yaml の形式が異なり、npm で npm install を実行した場合と pnpm で pnpm install を実行した場合で結果が異なる。特に devEngines で packageManager が pnpm に指定されている場合、npm コマンドは EBADDEVENGINES エラーで拒否される。使用するパッケージマネージャーはプロジェクトの設定で指定されているため、それに合わせてコマンドを使い分ける必要がある。
