git コマンドで、ファイルパス引数がリビジョン名に見える場合、git は ambiguous argument エラーを発生させます。

問題: git diff plugins/agent-policy/build.ts のように、パスがリビジョンのように見えるとエラーが出ます。

エラー例:
  git diff plugins/agent-policy/build.ts
  # 出力: fatal: ambiguous argument 'plugins/agent-policy/build.ts': unknown revision or path not in the working tree.

解決方法: git コマンドの引数にファイルパスを含む場合、-- を使って リビジョン と パス を明示的に分離します。

正しい形式:
  git diff -- plugins/agent-policy/build.ts
  git add -- plugins/agent-policy/hooks/hooks.json
  git checkout -- src/file.ts
  git show -- path/to/file.md

-- の位置は重要です。必ずリビジョン引数（ある場合）とパス引数の間に置きます。複数のパスを指定する場合も同様:
  git diff HEAD -- plugins/agent-policy/build.ts plugins/agent-policy/hooks/hooks.json
