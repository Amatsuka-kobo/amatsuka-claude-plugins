claude plugin validate --strict コマンドで author フィールド欠落警告により validation が失敗する場合、プラグインマニフェスト（plugin.json）に author フィールドを追加する必要があります。

--strict フラグは、warnings を errors として扱う strict mode。author 情報の欠落は warning として報告されますが、--strict では validation 失敗となります。

エラー例:
  ⚠ Found 1 warning:
  ❯ author: No author information provided
  ✘ Validation failed (--strict treats warnings as errors)

フィールド形式（plugin.json）:
  {
    "name": "plugin-name",
    "version": "1.0.0",
    "author": {
      "name": "Author Name",
      "email": "author@example.com"
    }
  }

または最小限:
  "author": "Author Name"

または:
  "author": {"name": "Author Name"}

プラグイン作成時、または既存プラグインの manifest を更新する際は、必ず author フィールドを含める。--strict validation は CI/CD パイプラインで多用されるため、author 欠落は build failure の原因になります。
