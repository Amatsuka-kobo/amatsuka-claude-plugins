Bash のヒアドキュメント内で JSON を構築し、Python の json.load() で検証する場合、バックスラッシュのエスケープが複雑になる。JSON キー・バリュー内に正規表現パターン（`\|` や `\\` など）が含まれるとき、Bash が一度エスケープを処理してから Python に渡すため、意図した JSON が組み立たない。例: `cat > file.json <<'EOF' { "pattern": "grep\\s+" }` では、`\\s` が `\s` に変換され、Python の json.loads() で "Invalid \\escape" エラーになる。対策: (1) JSON を手作業で構築せず、JSON ライブラリや出力ツール(jq など)で生成する、(2) ヒアドキュメント内で正規表現パターンの場合、シングルクォートで囲むか多重エスケープを検証する、(3) 複雑なパターンは別ファイルで管理する。
