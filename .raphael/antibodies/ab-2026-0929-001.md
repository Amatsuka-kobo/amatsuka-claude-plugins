Node.js の -e フラグでコードを実行する場合、__filename の値は [eval] となり、実ファイルパスではない。require("module").createRequire(__filename) を -e スクリプト内で使用するとエラー ERR_INVALID_ARG_VALUE が発生する。createRequire() は実ファイルパスまたは file:// URL を必要とする。-e で CommonJS モジュールを読み込む必要がある場合は、(1) コードをファイルに保存して実行する、(2) import.meta.resolve() などの他の API を使う、(3) 絶対パス文字列を明示的に渡す、のいずれかを検討すること。
