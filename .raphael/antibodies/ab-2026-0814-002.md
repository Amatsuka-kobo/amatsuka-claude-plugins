Biome/dprint は、indentation・spacing・quote format などコード整形ルールを厳密に検証する。

複数行にわたるコード（関数定義、長い式など）を改行してインデント入る場合、Biome の indentation ルールに合わせる必要がある。

例 (誤)：
  const alias = options.aliases.get(template.name) ?? profile.defaultAlias(template.name)

例 (正)：
  const alias =
    options.aliases.get(template.name) ??
    profile.defaultAlias(template.name)

Biome エラーメッセージで「Found N errors」と表示される場合、--fix で自動修正を試みるか、エディタで Biome 提案 indentation に従う。pnpm lint 実行前に、長い式は改行してインデント調整することで validation を通す。
