lindera-wasm の init() メソッドは WebAssembly モジュールを読み込む際に fetch API を使用する。Node.js 環境(特に WSL や一部のテスト環境)では、fetch が未実装またはスキーム(file://, data:) に対応していない場合、TypeError: fetch failed で失敗する。対策として:(1) Node.js 16.15+ を使用し undici の fetch が自動で有効か確認する、(2) 環境変数 NODE_NO_WARNINGS を設定して警告を抑制する、(3) WebAssembly モジュールを URL ではなく Buffer として読み込むか、(4) Node バージョンアップグレードやフォールバック実装を検討する。
