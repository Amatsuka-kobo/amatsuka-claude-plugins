Bash で grep コマンド内のグロブパターン(*)を含むコマンドを実行する場合、単一引用符で囲まれた文字列内のパターンはシェルが展開しない。例：`grep ... pattern dir/*` では、`*` は引用符の外にあるため展開されるが、`grep ... dir/*` の後に他のオプション(2>/dev/null)が続く場合、グロブパターンが展開される前にディレクトリが存在することを前提としている。該当ディレクトリが存在しない場合、grep exit code 2(エラー)で失敗する。対策として、(1) grep 実行前に `ls $dir 2>/dev/null | head` でディレクトリ内容を確認する、(2) shopt -s nullglob で無マッチ時に空文字列を返す設定にする、(3) find で存在確認する。
