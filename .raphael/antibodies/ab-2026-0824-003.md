vitest の -t フラグは、テストの名前パターン（正規表現または部分文字列）を指定するオプションです。値に --check のようなダブルハイフォプション形式の文字列を渡すと、vitest が誤ってそれを独立したオプションフラグとして解釈し、"Unknown option" エラーで失敗します。

例 (誤り):
  pnpm vitest run --file.ts -t "--check"
  # 出力: Unknown option `--check`

例 (正しい):
  # パターンとしてテスト名を指定（ダブルハイフなし）
  pnpm vitest run --file.ts -t "check"
  # または正規表現で match
  pnpm vitest run --file.ts -t "check.*test"

-t の値に --prefix がある場合は、その値を正規表現の一部として扱いたいとしても、vitest パーサは -- を新しいオプション開始と判定します。値にダブルハイフを含める必要がある場合は、引用符で囲み、--opt=value 形式ではなく -t "pattern" 形式で渡す必要があります。値そのものに -- を含めるのは避け、かわりに含める文字列を pattern として指定する。
