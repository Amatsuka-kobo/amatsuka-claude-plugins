ls コマンドで複数のパスを指定した場合、一部のパスが存在しないと exit code は 2(エラー)になる。ls /path1 /path2 /nonexistent のように、存在しないパスを含むと、そのパスについては "cannot access" エラーを出力し、同時に他の有効なパスについては正常に列挙するが、全体的には exit code 2 で終了する。ファイルの存在確認に ls を使う場合は、test -f や test -d を使う方が安全。または、ls が失敗してもスクリプト全体を停止しないようにするなら、exit code を明示的に処理する(例: ls ... || true)。
