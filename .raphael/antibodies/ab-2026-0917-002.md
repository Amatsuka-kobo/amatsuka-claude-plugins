urllib.request.urlopen での外部 API 呼び出しは、timeout パラメータを指定していても、ネットワーク障害・レート制限(HTTP 429)・サーバー側の auth エラー(HTTP 401/403)などが発生する。timeout 内に HTTP エラーが返された場合は ValueError ではなく urllib.error.HTTPError として例外が発生する。rate limit や一時的なサーバー障害に対して、自動リトライ、遅延リトライ、またはエラーログ記録の仕組みが必要になることが多い。
