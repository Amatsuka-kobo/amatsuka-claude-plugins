task-utility の commit-chat-recording.mjs で body ファイルが validation に失敗する場合、body ファイルが empty または size limit を超えていないか確認する必要があります。

エラー: "record body is empty or too large"

根本原因: prepare-chat-recording.mjs コマンドの失敗（必須フラグの欠落、ファイルパス誤り、transcript 検証失敗など ab-2026-0731-001 参照）により、body ファイルが生成されていない or 空の状態。

原因1: prepare-chat-recording.mjs の実行失敗（ab-2026-0731-001 で列挙される必須フラグ欠落）
原因2: prepare-chat-recording.mjs は成功したが、output body ファイルが empty のまま（session heading のみで content がない）
原因3: body ファイルサイズが上限（デフォルト数MB）を超えている

解決方法:
1. prepare-chat-recording.mjs の実行ログ・exit code を確認。失敗していれば ab-2026-0731-001 に従い必須フラグをすべて指定して再実行
2. body ファイルが存在し、サイズが 0 でないか確認
   test -s /path/to/body.md || (echo "body file empty"; exit 1)
3. body ファイルの先頭5行を確認。session heading + 実際のコンテンツを含むか
   head -20 /path/to/body.md
4. chat-recorder エージェントが dispatch したコマンドをそのまま使う。手書きで値を構築しない（ab-2026-0731-001）
