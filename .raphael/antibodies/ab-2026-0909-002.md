grep と ripgrep (rg) は、複数ディレクトリを検索する際に、見つからないディレクトリやエラー状態が発生した場合に exit code 2 を返す。exit code 1(見つからない) と 2(エラー) を区別して処理する必要がある。`2>/dev/null` でエラーを抑止しても exit code は変わらないため、検索対象が存在することを事前確認するか、exit code の扱いを明示的に指定すべき。
