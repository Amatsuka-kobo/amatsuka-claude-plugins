Node.js のテンプレートリテラルをシェルコマンドで Bash -e フラグ経由で渡す場合、バッククォートのエスケープが必要。

問題: node -e でダブルクォート内のテンプレートリテラルを使用すると、JavaScript パーサーが到達する前にシェルが処理し、バッククォートが評価される。

解決策:
1. シングルクォートを使用: node -e 'const s = `text`'
2. ダブルクォート内でバッククォートをエスケープ: node -e "const s = \\`text\\`"
3. JSON 引数経由で渡す: node -e 'JSON.parse(process.argv[1])' '{"key":"value"}'

原因: シェルの引用符層とJavaScript パーサーの層が混在するため、複数レイヤーのエスケープが必要。
