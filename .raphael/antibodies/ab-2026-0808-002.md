複雑なマルチラインjqコマンドをシェルで実行する場合、改行がスペース置換される可能性がある。

問題: マルチラインjqコマンド（複数行のパイプ、map/select ネスト等）を Bash ツール経由で実行すると、改行がスペースに置換され、jq パーサが構文エラーで fail。

エラー: exit code 5, jq parse error

原因: Bash ツールでの改行は実際の改行ではなくスペースに置換される。jq に複数行スクリプトを埋め込むと、改行に依存する構文が壊れる。

解決方法:
1. jq スクリプトをファイルに保存し、-f で指定
   cat > /tmp/filter.jq << 'EOF'
   map(select(...))
   | .[] | {key: .value}
   EOF
   jq -s -f /tmp/filter.jq file.json

2. または、単一行構文に整理（パイプを | で連結、改行を避ける）
   jq -s 'map(select(...)) | .[] | {key: .value}' file.json

3. Bash ツール経由ではなく、エージェント内の標準 JSON 処理を使う。複雑なフィルタはスクリプト分割を検討

複雑なマルチラインコマンドは Bash ツールで改行依存させず、-f ファイル指定か単一行構文に整理する。
