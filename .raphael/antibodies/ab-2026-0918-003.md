git diff --check はファイルの末尾の不要な空行や行末の空白(trailing whitespace)を検出し、警告を出す。警告のある状態で git commit を実行すると(--no-verify がなければ)pre-commit フックによって拒否されることがある。ファイルを編集した際は git diff --check で警告を事前に確認し、末尾の空行を削除するか、明示的に --no-verify で強制する必要がある。特にマークダウンファイルやスクリプトでは行末の whitespace が蓄積しやすい。
