TypeScript プロジェクトの lint（dprint など）では、import ステートメントの順序が規定されていることが多い。通常のルールは 1) dependencies（node_modules） 2) local modules（./ や ../） の順。

問題: import ステートメントが乱雑に配置されると、linter が並び替えを提案し、手動修正が必要になる。

例（誤り）：
  import { generateHtml } from "./generate-report.js"
  import { improveDescription } from "./improve-description.js"
  import { type ImproveOptions } from "./improve-description.js"

例（正しい）：
  import {
    improveDescription as defaultImproveDescription,
    type ImproveOptions
  } from "./improve-description.js"
  import { generateHtml } from "./generate-report.js"

TypeScript では type imports を grouped imports に統合し、各モジュールの imports をまとめる。pnpm lint で提案された並び替えに従い、複数行に分かれた imports は統合する。
