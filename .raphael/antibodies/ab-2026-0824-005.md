Biome（dprint）のコード formatter は、行の長さ制限に従って長い行を複数行に分割し、また空行や末尾の空白を自動的に削除することがあります。

pnpm lint で「Formatter would have printed the following content」メッセージが表示される場合、Biome が提案した変更に従う必要があります。これは行の分割だけでなく、以下の場合も含みます：

- 行の長さに基づく分割（line-length ルール）
- 不要な空行の削除
- 末尾の空白の削除
- コードブロック間の空行調整

例（誤り）:
  const roles = [...loadFragments(fragmentDirs(options.dir), options.vendor).values()].sort((left, right) => roleOrder(left.id) - roleOrder(right.id))

例（正しい）:
  const roles = [
    ...loadFragments(fragmentDirs(options.dir), options.vendor).values()
  ]
    .sort((left, right) => roleOrder(left.id) - roleOrder(right.id))

また、biome formatter が空行削除を提案した場合（例：describe ブロック間の空行削除）も、提案に従って削除します。

解決方法:
1. pnpm lint で提案された形式に従い、コードを再フォーマットする
2. または biome CLI で --write フラグを使用して自動修正
   pnpm lint --write
3. 最初から行の長さを意識し、不要な空行を避けて書く（推奨）

linter の提案を無視してコミットすると、pre-commit hook で再度失敗します。Biome の formatter ルールに従い、提案されたすべての変更を適用します。
