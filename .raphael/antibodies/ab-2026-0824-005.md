Biome（dprint）のコード formatter は、行の長さに上限を設定し、その制限を超える長い行を自動的に複数行に分割する。

pnpm lint で「Formatter would have printed the following content」メッセージが表示される場合、Biome が提案した行分割に従う必要がある。

例（誤り）:
  const roles = [...loadFragments(fragmentDirs(options.dir), options.vendor).values()].sort((left, right) => roleOrder(left.id) - roleOrder(right.id))
  # Biome は次のように分割を提案
  const roles = [
    ...loadFragments(fragmentDirs(options.dir), options.vendor).values()
  ]
    .sort((left, right) => roleOrder(left.id) - roleOrder(right.id))

長い文字列や関数呼び出しチェーン、メソッドチェーンは、行の長さ制限に応じて自動的に分割される。

解決方法:
1. pnpm lint で提案された形式に従い、コードを再フォーマットする
2. または biome CLI で --write フラグを使用して自動修正
   pnpm lint --write
3. 行の長さを意識して最初から短い行で書く（推奨）

linter の提案を無視してコミットすると、pre-commit hook で再度失敗する。Biome の line-length ルール（デフォルト 80-100 文字）に従い、長い表現は意図的に分割する。
