Bash のシェル &&(AND) チェーンでは、左側のコマンドが失敗すると、右側は実行されず全体の exit code は失敗(1)になる。複合コマンド `test -f file && other_cmd` で file が存在しない場合、test が exit code 1 を返し、シェル全体も exit code 1 で終了する。ファイル存在確認と続行を分離したい場合は、失敗を許容する || true を使うか、check と continue を別のコマンドに分けて各々の exit code を無視する。複数のコマンドを && でチェーンする場合は、どのコマンドで失敗が想定されているかを明確にし、必要に応じて || や || true で exit code を調整する。
