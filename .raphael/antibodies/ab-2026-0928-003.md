Bash のシェル &&(AND) チェーンでは、左側のコマンドが失敗すると、右側は実行されず全体の exit code は失敗(1)になる。`test -f file && other_cmd` や `test -d dir && { ...; }` のように test の条件が偽のとき、test が exit code 1 を返し、シェル全体も exit code 1 で終了する。for ループの中で使うと、最後の反復の判定結果がループ全体の exit code になる。存在確認と続行を分けたい場合は `if test -d dir; then ...; fi` と書くか、失敗を許容する || true を付け、どのコマンドで失敗が想定されているかを明確にする。
