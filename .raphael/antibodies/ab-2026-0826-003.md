Node.js プロジェクトが pnpm workspace として構成されている場合、npm または npx で直接 tsx/node_modules/.bin のバイナリを実行しようとすると、devEngines validation エラーで失敗する。

エラー:
  npm error EBADDEVENGINES Invalid name "pnpm" does not match "npm" for "packageManager"
  npm error EBADDEVENGINES The developer of this package has specified the following through devEngines

原因: pnpm workspace の package.json は devEngines.packageManager に pnpm を指定している。npm でこのプロジェクトを操作しようとすると、npm の packageManager 検証が失敗する。

解決方法:
1. pnpm を使用（推奨）:
   pnpm tsx script.ts
   pnpm exec tsc --noEmit
   pnpm vitest run

2. または Node.js を直接実行:
   node -e "..."
   node script.mjs

3. npm を使わない。npx も同様に失敗する。

pnpm workspace 環境では、npm コマンドによる操作は workspace validation で全て拒否される。必ず pnpm を使用する。
