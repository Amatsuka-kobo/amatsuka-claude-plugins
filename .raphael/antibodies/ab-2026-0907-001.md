agent-policy의 roles.ts에 새로운 역할을 추가했을 때, policies.ts의 역할 할당표와 __test__/policy-skill-assignments.test.ts의 expect 스테이트먼트를 함께 업데이트하지 않으면 lint와 test가 동시에 실패합니다.

증상:
- lint 실패: biome formatter가 expect 문의 라인 길이나 들여쓰기 수정 제안
- test 실패: "custom-policy/ROLE_ID: SKILL=[] RECOMMENDED=[...]"

근본 원인:
1. roles.ts에서 새 역할 ID 정의 (예: "escalation", "e2e-verify")
2. 하지만 policies.ts의 ASSIGNMENTS 객체에서 해당 역할의 모델 배열이 모든 정책(custom-policy, claude-policy 등)에 누락
3. test의 expect(roleLabel({}, "NEW_ROLE")).toBe("...") 형식 업데이트 누락

해결 단계:
1. lint와 test가 동시에 실패하면, 먼저 roles.ts를 열어 새로 추가된 역할 ID 확인
2. policies.ts의 ASSIGNMENTS 객체에서 각 정책의 해당 역할 항목이 있는지 확인 (undefined면 추가 필요)
3. policy-skill-assignments.test.ts의 expect 스테이트먼트를 biome 제안에 따라 수정
4. pnpm run lint && pnpm run test 로 재검증

roles 수정 후 policies 할당과 test 업데이트는 반드시 함께 진행해야 합니다.
