prompt-smith プラグインの scripts/generate-report.mjs は、--eval-set フラグが必須です。

問題: --eval-set フラグなしで scripts を実行すると、スクリプトが標準出力に "--eval-set is required" と出力して終了コード 1 で失敗する。

エラー例:
  node plugins/prompt-smith/scripts/generate-report.mjs
  # 出力: --eval-set is required
  # exit code: 1

正しい実行例:
  node plugins/prompt-smith/scripts/generate-report.mjs --eval-set <path-to-eval-set.json>

generate-report.mjs を単独実行する場合は、--eval-set に評価セット JSON ファイルのパスを指定する必要があります。smoke test や確認スクリプトで呼ぶ際も必須フラグを省略しないこと。
