curl で `%{http_code}` で HTTP ステータスコードを取得し、3XX リダイレクト・429 Too Many Requests・その他のエラーコードを処理する場合、$? のステータスコード(transfer success/failure)と HTTP コードは異なる。-f / --fail フラグで HTTP エラー時に curl 自体を失敗させるか、http_code を明示的に検査して分岐する必要がある。リダイレクト(302)や rate limit(429) に対して curl が exit code 0 で戻る場合がある。
