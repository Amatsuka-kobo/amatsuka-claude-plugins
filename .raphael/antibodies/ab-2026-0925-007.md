Playwright の getByRole() メソッドは strict mode で複数の要素にマッチする場合、"strict mode violation" エラーを発生させる。これは、意図した単一の要素にマッチするように指定不足がある場合に起こる。getByRole() を使う際は、必ず name オプションを指定し、複数の要素がマッチする可能性がある場合は exact: true を指定する、またはより具体的なロール(例: button.button-primary)や他のセレクタ(getByText, getByLabel など)の組み合わせを検討すること。
