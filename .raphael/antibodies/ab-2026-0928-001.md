node -e でシェル経由で複雑な JavaScript を実行する場合、シェルのクォーティングやエスケープが失敗することがある。特に複数行の関数定義、複雑な正規表現（括弧や量指定子を含む）、文字列内の引用符を含むコードは Bash の eval で構文エラーになりやすい。対策として、複雑な JavaScript は -e に詰め込まず、別のスクリプトファイルとして保存してから実行する。-e は単純な一行コマンドやテストに限定する。
