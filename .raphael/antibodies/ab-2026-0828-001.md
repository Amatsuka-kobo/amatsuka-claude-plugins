Agent YAML metadata in .claude/agents/*.md can have composite agent-policy-role values separated by commas and spaces (e.g., 'normal-impl, general', 'explore, realtime-research'). When parsing these role markers to build mappings or tables, split composite role strings on comma-space to get individual role names before using them as dictionary keys. Direct lookup of the composite string will fail with KeyError. Python: for role_val in roles_data: role_list = role_val.split(', '); for individual_role in role_list: process(individual_role)
