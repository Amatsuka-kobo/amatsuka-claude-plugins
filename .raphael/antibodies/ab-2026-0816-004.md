task-utility の commit-chat-recording.mjs で新規レコード作成時、--record-path フラグは docs/chat/YYYY/MMDD/username/<kebab-case>.md の形式に厳密に従う必要があります。

エラー: "new record path violates the naming or directory contract"

問題: 相対パスや異なるディレクトリ構造を指定すると、フォーマット検証で拒否されます。

例 (誤)：
  commit-chat-recording.mjs \
    --record-path 2026/0816/phyllis998/metatron-sandalphon-implementation-request.md
  # 出力: new record path violates the naming or directory contract: expected docs/chat/2026/0816/phyllis998/<kebab-case>.md

例 (正)：
  commit-chat-recording.mjs \
    --record-path docs/chat/2026/0816/phyllis998/metatron-sandalphon-implementation-request.md

--record-path は必ず docs/chat/ プレフィックスで始まり、その後に YYYY/MMDD/username/kebab-case-filename.md の形式で指定する。相対パスだけでなく docs/chat/ ディレクトリ接頭辞が必須です。
