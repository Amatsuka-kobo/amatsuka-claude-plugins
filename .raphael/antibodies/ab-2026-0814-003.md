JSON ファイルを head -c でバイト数制限取得する場合、JSON 構造の途中で切断される可能性がある。

jq がそのような途中で切断された JSON をパースしようとすると "Unfinished string at EOF" で失敗する。

例 (誤)：
  head -c 3000 large-file.json | jq .key
  # 出力: jq: parse error: Unfinished string at EOF at line 1, column 3000

例 (正)：
  # 方法1: cat で全体を処理
  cat large-file.json | jq .key

  # 方法2: 行数制限（JSON Lines 形式）
  tail -n 100 large-file.jsonl | jq .key

  # 方法3: head -n で行数制限（完全な JSON 行を確保）
  head -n 50 large-file.json | jq .key

  # 方法4: jq -s で slurp（全体を array として読込後フィルタ）
  jq -s .[] large-file.json

部分取得が必要な場合は、バイト数制限（head -c）ではなく、行数制限（head -n、tail -n）か、JSON 構造を考慮した適切なフィルタを選択する。head -c は JSON parse には不適切。
