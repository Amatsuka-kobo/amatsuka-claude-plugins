pkill -f <パターン> は、プロセスの完全な command line にパターンを含むものすべてに一致する。パターンを書いた Bash コマンド自身を実行している shell(bash -c の引数にそのコマンド文字列が入る)も一致するため、pkill は呼び出し元の shell を殺すと推定される。その場合、後ろに `; true` を付けても shell ごと終わるため防げず、コマンドは pkill の通常の終了コード 1(マッチ 0 件)とは別の値で失敗する。対策は次のいずれか。パターンをブラケット書法にする(`[f]ind` は find に一致するが、自分の command line には `[f]ind` と書かれるため一致しない)。pgrep -f で PID を取得し、自分の $$ を除外してから kill する。PID を直接指定する。
