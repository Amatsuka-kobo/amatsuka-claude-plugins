pkill -f matches against the process name including the full command line arguments. Patterns containing file paths like '/' or 'root' may match unintended processes across multiple command invocations. Use specific process names, PIDs, or narrow the filter criteria. Exit codes from pkill can be unusual (e.g., 144) if no matching process is found or the process list changes during execution. Consider using explicit PIDs or checking if the process exists before attempting to kill it.
