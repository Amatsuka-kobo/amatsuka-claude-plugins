Bash ツール経由でコマンドを実行する際、環境変数（例：CLAUDE_PROJECT_DIR、PROJECT_DIR）は自動的に設定されていないと想定する必要があります。

問題: コマンド内で $CLAUDE_PROJECT_DIR を参照すると、その変数が未設定の場合、""（空文字列）に展開され、コマンドが無効なパスで実行されます。

例（失敗）:
  ls -la "$CLAUDE_PROJECT_DIR/.raphael/"
  # 変数未設定時: ls -la "/.raphael/"
  # 出力: cannot access /.raphael/: No such file or directory

解決方法:

1. 絶対パスを直接使う（推奨）:
   ls -la /home/hiro0209/amatsuka-kobo/amatsuka-claude-plugins/.raphael/

2. または実行前に変数を明示的に設定:
   CLAUDE_PROJECT_DIR=/home/hiro0209/amatsuka-kobo/amatsuka-claude-plugins
   ls -la "$CLAUDE_PROJECT_DIR/.raphael/"

3. または変数が設定されていることを確認してから使用:
   if [ -z "$CLAUDE_PROJECT_DIR" ]; then
     CLAUDE_PROJECT_DIR=/home/hiro0209/amatsuka-kobo/amatsuka-claude-plugins
   fi
   ls -la "$CLAUDE_PROJECT_DIR/.raphael/"

環境変数に依存せず、絶対パスを使うか、変数設定を明示的に行うことで、予測不可能な失敗を防ぐ。
