TypeScript プロジェクトで Biome（dprint など）が lint を実行する場合、string literal の引用符形式が統一されていることを確認する必要があります。

Biome のデフォルト設定では、プロジェクト全体で引用符のスタイルを統一するルールがあります。通常は double quotes ("...") が推奨されますが、プロジェクトによって異なります。

問題: test ファイルや新しいコードで単発的にシングルクォート ('...') を使用すると、lint が引用符のスタイル不一致を指摘し、linter が修正を提案します。

例（誤り）:
  expect(html).not.toContain('<script>alert(1)</script>') // シングルクォートで統一されていない

例（正しい）:
  expect(html).not.toContain("<script>alert(1)</script>") // ダブルクォートで統一

リント実行前に、ファイル内のすべての string literal が同じ引用符スタイルを使用していることを確認する。既存コードベースの引用符スタイルに従う。dprint/biome の safe fix では自動的に統一されるため、提案通りに修正を適用する。
