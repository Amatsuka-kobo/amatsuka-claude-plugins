task-utility の commit-chat-recording.mjs を実行する際、append の場合と新規作成の場合でフラグの可否が異なります。

## append 時（既存ファイルに追記）

append body ファイルが validation に失敗する場合、body ファイルに session heading が含まれているか確認する必要があります。

append する内容は session heading（例：## Session キーワード）から始まる必要があります。また、既存ファイルに append する場合は **--record-path フラグを指定してはいけません**（エラー: "--record-path is forbidden for an existing target"）。

原因1: body ファイルが空
原因2: body ファイルが session heading なしで開始
原因3: body ファイルの形式が不正
原因4: 既存ファイル対象で --record-path を誤指定

解決方法：
1. body ファイルの先頭に必ず session heading を含める
2. 例：## Session abc123
3. 既存ファイルに append する場合は --record-path を省略。新規作成時だけ --record-path を指定
4. prepare-chat-recording.mjs で body ファイルを生成した場合、session heading は自動挿入される。手動で body ファイルを作成する場合は、session heading を手動で追加する必要があります。
