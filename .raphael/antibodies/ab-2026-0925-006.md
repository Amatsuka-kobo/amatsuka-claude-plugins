Playwright で Chromium ブラウザを起動する際に、"error while loading shared libraries: libasound.so.2: cannot open shared object file" エラーが発生する場合がある。これは、WSL、Docker、または Linux サーバー環境などのヘッドレス環境で、オーディオライブラリ (ALSA: Advanced Linux Sound Architecture) が インストールされていないことが原因である。Playwright は音声を出力しない環境でも libasound.so.2 が必要。対処方法は、システムパッケージマネージャーで libasound2 をインストール (Ubuntu/Debian: apt-get install libasound2)、または Docker イメージで依存ライブラリを事前にインストールする。環境構築時に Playwright system dependencies のドキュメントを参照し、必要なライブラリをすべてインストールすること。
