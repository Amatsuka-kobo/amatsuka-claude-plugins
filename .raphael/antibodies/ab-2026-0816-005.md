JSONL (JSON Lines)形式のファイルに対して jq の .[] パターンを使用するとパースエラーで失敗する。

JSONL ファイルは、各行が独立した JSON オブジェクト。配列ではなく、複数の単一オブジェクトが連続している。jq の .[] は「配列の要素を展開」という意味だが、ファイル全体が配列でないため、最初の行が単一オブジェクトとして扱われ、そのオブジェクトに対して .field を実行すると失敗する。

例（誤り）:
  jq '.[] | select(.distilled==false)' file.jsonl
  # 出力: jq: error (at file.jsonl:1): Cannot index number with string "distilled"

例（正しい）:
  # 方法1: 各行を独立したオブジェクトとして処理（フィルタを直接適用）
  while IFS= read -r line; do
    echo "$line" | jq -e '.distilled == false' >/dev/null && echo "$line"
  done < file.jsonl

  # 方法2: jq -s で全行を配列として読込後に処理
  jq -s '.[] | select(.distilled==false)' file.jsonl

  # 方法3: grep で事前フィルタ
  grep '"distilled":false' file.jsonl | jq .

JSONL ファイルに対する jq は、各行が独立オブジェクトであることを意識し、.[] ではなく行ごとの処理か -s フラグを使う。
