task-utility の commit-chat-recording.mjs で新規レコード作成時、body ファイルが validation に失敗する場合、body ファイルが USER quote block を含んでいるか確認する必要があります。

新規作成時の body ファイルは、会話内容を markdown の引用ブロック形式で記録する必要があります。ユーザーの発言は "## USER" セクション下に "> " プレフィックスで記録する必要があります。

エラー: "record body must contain a USER quote block"

原因1: body ファイルに USER セクションが存在しない
原因2: USER セクションはあるが引用ブロック形式でない
原因3: body ファイルが空

解決方法：
1. prepare-chat-recording.mjs で生成された body ファイルテンプレートを確認する
2. ## USER セクション下に記録内容を > で引用ブロック形式で記録する
3. 例：
   ## USER
   
   > ユーザーの質問内容
4. 手動で body ファイルを作成する場合は、必ず USER セクションと引用ブロック形式を含める
5. record body はチャット会話を記録するため、USER 発言を含むことが必須。新規ファイル作成時は特に注意。
