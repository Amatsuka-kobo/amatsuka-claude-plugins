Node.js の node -e フラグで process.stdout.write() を使う場合、引数型が string である必要があります。入力データ（JSON配列等）がArray型の場合、直接渡すとTypeError [ERR_INVALID_ARG_TYPE] で失敗します。

問題:
  const data = JSON.parse(line)
  process.stdout.write(data.content)  // data.content が Array の場合、失敗

解決方法:
  const data = JSON.parse(line)
  if (Array.isArray(data.content)) {
    process.stdout.write(data.content.map(block => block.text).join())
  } else {
    process.stdout.write(data.content)
  }

または明示的に型変換:
  process.stdout.write(String(data.content))

node -e で外部データ（JSON等）を処理する場合は、出力前に型チェック or 型強制（String()）を行う。
