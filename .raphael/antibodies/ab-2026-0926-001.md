Biome code formatter enforces line length limits based on project configuration (biome.json). Lines exceeding the configured width (often 80 characters) are flagged as formatting errors during linting. When `pnpm run lint` fails with biome "Formatted string too long" or similar errors, the solution is to break long lines into multiple lines or restructure the expression to fit within the configured limit. Biome typically suggests the correct formatting in the error output.
