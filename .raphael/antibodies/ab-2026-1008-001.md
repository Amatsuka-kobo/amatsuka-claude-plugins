claude mcp list では、承認されていないプロジェクトスコープの .mcp.json のサーバーが「Pending approval」と表示され、起動しない。Claude Code 2.1.286 で、.claude/settings.local.json の enableAllProjectMcpServers を true にしても、enabledMcpjsonServers にサーバー名を入れても、同じ表示のままだった。未承認の間は、サーバーが起動してログを書いたかどうかで起動を確かめる方法は成立しない。承認済みのサーバーは「Connected」と表示される。
