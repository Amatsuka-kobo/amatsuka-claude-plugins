Bash commands passed to Claude Code's Bash tool with multi-line structure and backslash continuations (e.g., `git add -- \ file1 \ file2`) get normalized: actual newlines convert to literal `\ ` (backslash-space), breaking argument parsing. Git receives `\ plugins/codiel/...` instead of proper whitespace, failing with "pathspec did not match". Workaround: use printf to construct commands, pass files as separate arguments, or avoid backslash continuations in multi-file operations. Example: `printf '%s\n' file1 file2 | xargs git add --`.
