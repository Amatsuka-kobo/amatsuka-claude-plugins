JSON ファイルを head -c でバイト数制限取得する場合、JSON 構造の途中で切断される可能性がある。

jq がそのような途中で切断されたJSON をパースしようとすると "Unfinished string at EOF" で失敗する。

例 (誤)：
  head -c 3000 large-file.json | jq .key
  # 出力: jq: parse error: Unfinished string at EOF

例 (正)：
  # 方法1: jq -s で slurp（全体を array として取得）
  jq -s .[] large-file.json | head -c 3000
  
  # 方法2: tail で必要な行数を取得（JSON Lines 形式の場合）
  tail -n 100 large-file.jsonl | jq .key
  
  # 方法3: ファイルサイズ確認後、正確なバイト数を計算
  wc -c large-file.json  # ファイル全体のバイト数を確認
  cat large-file.json | jq .key  # 全体を処理

部分取得が必要な場合は、JSON の構造（array of objects, single object など）に応じて適切なフィルタ（head -n for lines, tail for tail lines）を選択する。バイト数制限（-c）は JSON parse には不適切。
