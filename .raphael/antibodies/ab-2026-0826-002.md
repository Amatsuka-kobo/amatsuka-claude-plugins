metatron.mjs のサブコマンド(stage-architecture, stage-adr, stage-rules, append-gotcha, tag-gotcha など)は --help フラグを個別サポートしない。BOOLEAN_FLAGS に "help" は含まれるが、各サブコマンドのハンドラはこのフラグを見ずに通常どおり --input または stdin からの JSON 入力を要求する処理へ進む。

結果として `metatron.mjs stage-architecture --help` のように実行すると、有効な --input も stdin も無いため次のエラーになる。

  {"error":"missing_input","message":"--input <path> が必要です。入力の JSON を一時ファイルに書いてからパスを渡してください。"}

これは異常動作ではなく、--input を渡さずに実行したときと同じ経路をたどっているだけである。サブコマンドの使い方を確認したいときは `<subcommand> --help` を試すのではなく、次のいずれかを使う。

- `node <plugin-root>/scripts/metatron.mjs help` — 全サブコマンドの usage 一覧(読み取り/段階/書き込み系の引数)を表示する
- `node <plugin-root>/scripts/metatron.mjs get config` — cli.stageArchitecture 等の呼び出し例と inputSchemas(各サブコマンドが要求する JSON 構造)を返す
