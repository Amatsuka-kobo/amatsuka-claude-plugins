cd コマンドでディレクトリに移動する場合、そのディレクトリが存在することを前提としている。cd 先のディレクトリが存在しない場合、cd は "No such file or directory" エラーで失敗する。ディレクトリを事前に作成する必要がある場合は、mkdir -p を使ってディレクトリ構造を作成してから cd を実行する。または、cd 実行前に test -d で存在確認を行うか、cd が失敗した場合の処理を明示的に指定する(例: cd ... || exit 1)。
