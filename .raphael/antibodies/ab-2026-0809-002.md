新規抗体（create）の expires は、作成日から 90 日以内に設定する必要があります。CLI が expires の検証時に、作成日から 90 日を超える値を拒否します。

問題: expires を作成日から 91 日以上先に設定すると、create コマンドが失敗します。

エラー例:
  Created: 2026-08-09
  Expires: 2026-11-08
  Days until expiry: 91
  ERROR: expires exceeds 90 days

解決方法:
1. expires を計算するときは、created_date + 90 日以内に収まるか確認
2. または管理 CLI で extend の上限仕様を確認し、90 日制約を理解する
3. 新規抗体の expires は最大で created + 90 日とする

90 日制約は update-antibody.mjs create の validation で強制されるため、迂回できません。新規抗体作成時は必ず 90 日以内の expires を指定してください。
