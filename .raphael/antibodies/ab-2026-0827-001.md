vitest は、テストファイルの検出に include/exclude パターンを使用します。デフォルト include パターンは plugins/**/__test__/**/*.test.ts で、このパターンに合致しないファイルは検出されません。

問題: vitest の直接実行時に "No test files found" エラーが出る場合、指定したファイルパスが include パターンに合致していることを確認する必要があります。

例（失敗）:
  vitest run plugins/agent-policy/src/hooks/subagent-start.test.ts
  # 出力: No test files found, exiting with code 1
  # 原因: テストファイルが src/hooks/ にあり、__test__/ 配下ではない

例（成功）:
  vitest run plugins/agent-policy/src/hooks/__test__/subagent-start.test.ts

解決方法:
1. テストファイルを __test__/ ディレクトリに配置する
2. または vitest.config.ts で include パターンをカスタマイズ
3. pnpm exec vitest で実行する場合は、プロジェクトルートからの相対パスか絶対パスを指定
