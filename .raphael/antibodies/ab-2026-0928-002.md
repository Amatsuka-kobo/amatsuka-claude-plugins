Python の json.loads() でパイプ経由で複数の JSON オブジェクトを処理する場合、json.loads は単一の完全な JSON を期待している。パイプで複数のオブジェクトが連結されていると、最初の JSON の終点を超えて追加データが検出され "Extra data" エラーで失敗する。複数の JSON オブジェクトを処理するには、まず rfind で最後の } の位置を特定するか、jsonl 形式として行ごとに処理するか、json.JSONDecoder.raw_decode() を使ってストリーム処理する。
