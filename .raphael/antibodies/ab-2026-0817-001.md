git コマンド実行時に「Unable to create '/path/to/.git/index.lock': File exists」というエラーが発生する場合、別の git プロセスが同じリポジトリで実行中である可能性がある。または前回の git コマンドが異常終了して lockfile が残っている。

このエラーが発生したら:

1. 別の git プロセスが実行中でないことを確認
   ps aux | grep git

2. .git/index.lock ファイルを削除
   rm /path/to/.git/index.lock

3. 元の git コマンドを再実行
   git commit -m "..."

エラー例:
  $ git commit -m "message"
  fatal: Unable to create '/home/user/project/.git/index.lock': File exists.
  Another git process seems to be running in this repository, e.g.
  an editor opened by 'git commit'. Please make sure all processes
  are terminated then try again.

解決後も同じエラーが出る場合、.git/index.lock の日時を確認し、明らかに古い場合は削除。ただし git プロセスが本当に実行中ならば、プロセスを終了してから削除する。
