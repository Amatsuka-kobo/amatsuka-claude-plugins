vitest run コマンドに特定のテストファイルパターンを指定しても、そのパターンにマッチするファイルが実際に存在しない場合、vitest は exit code 1 で "No test files found" エラーで終了する。ファイルパターン(glob やファイルパス)を指定する際は、事前に ls や find でファイルが存在することを確認するか、ワイルドカードパターンが期待通りマッチすることをテストすること。特に新しいテストファイルを作成する際に、既存のテストスイートを実行する前にファイルが正しく配置されていることを確認する必要がある。
