task-utility の commit-chat-recording.mjs は複数の必須フラグと validation を持つ。

必須フラグ（append と create 両方）:
  --project          プロジェクトディレクトリパス
  --session-key      セッションキー
  --attempt-id       試行 ID
  --target-line      記録対象の行番号(正の整数)
  --body-file        body ファイルパス
  --index-line-file  index-line ファイルパス

append 時の必須フラグ:
  --session-title-file  session title ファイルパス（append でも必須）

validation エラー例と原因:

1. 「missing --session-title-file」
   原因: --session-title-file フラグを指定していない
   解決: --session-title-file を追加

2. 「plan.sessionNumber must be a positive integer」
   原因: session number が不正（0 未満、文字列等）
   解決: session-title ファイルの内容を確認。sessionNumber の値が正の整数になっていることを確認

3. 「append body must contain a session heading」
   原因: body ファイルが ## Session ... で開始していない
   解決: body ファイルの先頭に ## Session キーワードを含める

4. 「session title must be exactly one bounded line」
   原因: session-title ファイルが複数行または空
   解決: session-title ファイルは単一行（タイトル文字列のみ）で構成する必要がある

commit-chat-recording.mjs 実行時は、prepare-chat-recording.mjs で生成された body ファイルと session-title ファイルをそのまま使用することを推奨。手動で値を構築する場合は、生成ファイルの形式を参考にしてフラグを正確に指定する。
