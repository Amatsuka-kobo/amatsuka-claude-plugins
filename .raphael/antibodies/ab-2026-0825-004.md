TypeScript の execFileSync() に stdio オプションを渡す場合、stdio 配列は readonly 型ではなく mutable 型である必要があります。

問題: 型エラー TS2769
  Argument of type '{ encoding: "utf8"; stdio: readonly [...]; ... }' is not assignable to parameter of type 'ExecFileSyncOptions'

原因: stdio が readonly ["ignore", "pipe", "pipe"] として定義されているが、execFileSync のオーバーロード型は StdioOptions = (number | Stream | IOType | "ipc" | null | undefined)[] という mutable 配列を期待している。

解決方法:

1. stdio 配列の型アノテーションを削除し、リテラル配列として扱う（推奨）
   // 誤り
   const options = {
     stdio: readonly ["ignore", "pipe", "pipe"]
   }

   // 正しい
   const options = {
     stdio: ["ignore", "pipe", "pipe"] as const
   }

2. または明示的に型キャストする
   const options = {
     stdio: ["ignore", "pipe", "pipe"] as unknown as StdioOptions
   }

3. または変数に readonly を付けず通常の配列で定義
   const stdio = ["ignore", "pipe", "pipe"]
   const options = { stdio }

readonly 制約は execFileSync の型安全性と合わないため、stdio オプション付き呼び出しでは mutable 配列を使う。
