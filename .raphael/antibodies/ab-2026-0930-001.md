chat-history プラグインの commit-chat-recording.mjs スクリプトは、session の attempt/lock/plan 状態を管理している。エラー "attempt/lock/plan mismatch" が発生する場合、session 管理の state が不整合の状態にある。前の session のロックが残っていたり、plan が進んでいないか、複数の session が同時にアクセスしている可能性がある。対処として、session state を確認するか、chat-history の state ディレクトリをクリーンアップしてからリトライする。
