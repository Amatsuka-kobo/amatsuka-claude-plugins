TypeScript / Node.js で相対パスのモジュール import を使う場合、cd コマンドで cwd を変更した後に tsx や node コマンドを実行すると、import の解決パスが change された cwd 基準になるため、相対パスが見つからなくなる可能性がある。スクリプト実行時は cwd の影響を考慮し、相対 import の解決パスが正しいことを確認する。
