task-utility の prepare-chat-recording.mjs は 5 つのフラグがすべて必須で、1 つでも欠けると missing <flag> で失敗する。

必須フラグ(全部):
  --project       プロジェクトディレクトリパス
  --transcript    トランスクリプトファイルパス(--transcript-path ではない)
  --session-key   セッションキー
  --attempt-id    試行 ID
  --target-line   記録対象の行番号(正の整数)

誤り例:
  node prepare-chat-recording.mjs --project /path            # 他 4 フラグ欠落で失敗
  node prepare-chat-recording.mjs --transcript-path /t.jsonl  # フラグ名誤り。正しくは --transcript
  node prepare-chat-recording.mjs --help                      # --help は未対応。必須フラグ欠落で失敗

正しい例:
  node prepare-chat-recording.mjs \
    --project /home/user/project \
    --transcript /path/to/transcript.jsonl \
    --session-key xxx \
    --attempt-id yyy \
    --target-line 469

通常はこのコマンドを手書きせず、chat-recorder エージェントの dispatch prompt で渡された値をそのまま使う。
