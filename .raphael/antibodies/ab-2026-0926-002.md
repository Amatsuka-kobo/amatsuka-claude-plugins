Ripgrep (rg) regex patterns treat curly braces `{` and `}` as special characters for repetition quantifiers (e.g., `a{3,5}` matches 3-5 occurrences). When unescaped braces appear in a pattern intended as literals, the regex parser fails with "repetition operator missing expression" error. To include literal braces in a ripgrep pattern, escape them with backslash: `\{` and `\}`. Alternatively, use the `-F/--fixed-strings` flag to treat the entire pattern as a literal string instead of interpreting it as regex.
